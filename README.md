# Everline

A date-first notebook for macOS and iOS. Every day has its own note, and a strip of the current week lets you move
between days.

## Features

- Opens on today's note, ready to type.
- A seven-day strip with previous and next week arrows. The week starts on your system's first day of the week.
- Each day keeps its own text while the app runs. Notes are not saved yet.
